# CCI Sea State {{cci_version}} Product User Guide

This document presents the Product User Guide (PUG) for CCI Sea State 
datasets {{cci_version}}. It describes the different datasets produced within 
the **ESA CCI Sea State** project, built upon state-of-the-art algorithms for 
the retrieval of sea state parameters, tracing also their evolutions and changes.

Currently, the version up to date is the fourth, ({{cci_version}}) 
that have been made available in August 2025; this release improves and extends 
the version 1 and 3 altimeter time series for the period 2002 to 2024 and adds 
new products from the Synthetic Aperture Radar (SAR) instrument IW/EW image 
modes.
